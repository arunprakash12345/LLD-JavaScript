# LLD-JavaScript

This repository contains my practice for Low-Level Design (LLD) and frontend machine coding questions using JavaScript, HTML, and CSS.

The goal is to improve problem solving, DOM manipulation, event handling, and component building skills through hands-on practice.

## Projects

* Accordion
* OTP Input
* Chess Board - Bishop Movement
* More components and LLD questions will be added regularly

## Tech Stack

* JavaScript
* HTML
* CSS

## Purpose

I created this repository to practice common frontend LLD questions asked in interviews and improve my JavaScript skills by building them from scratch.

## Run Locally

```bash
git clone https://github.com/arunprakash12345/LLD-JavaScript.git
```

Open any project folder and run the `index.html` file in the browser.
